# Ideological bundle performance

This analysis first audits whether an issue contains meaningful observations at both poles. Sparse and one-sided headline dimensions are excluded from clustering, so absence of one viewpoint cannot manufacture a candidate archetype.

The selected solution has **6 bundles**, uses **6 headline dimensions**, and requires at least **3 observed dimensions** per candidate. Missing retained dimensions are median-imputed only for cluster assignment; reported profiles and election outcomes remain observed data.

## Dimensions retained

gun_rights, market_and_development_autonomy, material_redistribution, punitive_law_and_order, racial_and_political_equality, social_traditionalism

## Dimensions excluded

institutional_democratic_reform, labor_power, public_services

## Interpretation limits

Bundles are descriptive clusters, not causal effects. Their apparent performance may reflect geography, candidate selection, era, and uneven evidence coverage. Era-specific results with small n should be treated as exploratory.
