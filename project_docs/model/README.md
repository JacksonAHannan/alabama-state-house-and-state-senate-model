# Model and research documents: which ones govern?

Use [Canonical pipelines](../CANONICAL_PIPELINES.md) to find the four current
product routes, their contracts, and named validation records. A versioned
document in this directory does not become current merely because its filename
contains “headline,” “readiness,” or a higher version number.

- Current route contracts control the selected product, subject to their stated
  coverage, validation and dependency limitations.
- Older CMO definitions, forecast challengers/tournaments, and proposal documents
  are historical research or compatibility references, not default release rules.
- Research-only products remain research-only until explicitly reviewed for
  promotion. Documentation cleanup does not approve a model or alter a gate.
- Generated reports and manifest-linked documents retain their original bytes;
  consult the named run before interpreting “current,” “complete,” or “PASS.”
- Old coverage tables and readiness lists are snapshots. Remaining project work
  belongs in the [internal checklist](../PROJECT_COMPLETION_CHECKLIST.html).

The [documentation inventory](../audits/documentation_inventory_2026_09_05.csv)
gives each scanned document a disposition, reference flags and a pre-audit hash.
This classification is not a new verification of the underlying research.
