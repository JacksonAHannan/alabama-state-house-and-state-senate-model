# CMO methodology v3: direct ticket overperformance

## Headline estimand

The headline CMO is the party-oriented difference between the legislative margin and the source-aware same-district ticket baseline. It does not residualize the result a second time using demographics, incumbency, finance, ideology, or candidate history.

Regression-based context expectations are retained only in the pathology audit. Career scores are separately labeled partial-pooled summaries; they do not replace election-level CMO.

## Morrow 1998 HD-18 reconciliation

- Legislative Democratic margin: 15.599
- Source-aware ticket baseline: 15.089
- Headline CMO: 0.510
